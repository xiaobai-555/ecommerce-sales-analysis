口径说明：主线聚焦 USD 计价订单（82,600 单，占 60%），规避 7 种货币混算；订单指标用 Completed，退货/渠道/用户分析用 Completed + Returned。
核心结论
1. 折扣红线：40%
毛利率随折扣加深单调下滑：50% → 40% → 29% → 19% → 4%。
40% 以上折扣档贡献 11.3% 营收，却仅 1.4% 毛利 → 建议促销折扣上限设为 40%。
2. Electronics 是结构性薄利品类
贡献 21% 营收（第一）但毛利率仅 27%（最低）。
逐一排除「折扣」（各品类折扣率均为 16.5%–16.9%）和「退货」（6.9%，中等水平）两个假设后，定位根因为成本率 60% 全场最高（Grocery 仅 37%）。
→ 建议定位为引流款、控制占比，用高毛利品类（Grocery 49%、Books 47%、Beauty 45%）承接利润。
3. 渠道无显著差异，靠老客支撑
4 大销售渠道 + 10 个营销渠道的毛利率（35.7%–36.3%）、退货率、老客占比高度接近；93%+ 订单来自老客。
→ 建议维持多渠道布局，运营重心放在老客复购。

技术栈
- SQL（MySQL）：数据清洗、多表关联、窗口函数、分组聚合
- Python（Pandas）：数据核对与交叉验证
